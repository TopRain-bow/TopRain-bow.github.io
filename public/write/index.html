第一次使用：粘一个令牌（只存你自己的浏览器里）

浏览器里的静态页面本身没有权限往 GitHub 写东西，必须带一个属于你的凭据。粘一次就行，之后打开这个页面可以直接写。

  1. 打开 创建令牌 （权限已预填好 Contents: Read and write）
  2. 仓库那一栏选 TopRain-bow.github.io，然后点最下面的 Generate token
  3. 复制 github_pat_... 粘到下面，点保存
